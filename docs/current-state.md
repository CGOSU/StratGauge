# 当前状态

## 项目

- 名称：`StratGauge`
- 定位：是一个把个人选股和买卖策略自动化、用历史数据与机器学习评估胜率和风险，并由用户手动决策交易的 A 股 AI 策略助手

## 当前目标

- 阶段 0 的实现检查点 1—6 已完成，代码退出验收通过；真实 AKShare 主源集成因当前代理连接失败仍未通过。
- 新增无额外数据平台费用的半手动闭环：通达信导出选股结果，系统人工标注，随后用日线跟踪并自动生成结果、统计和机器学习样本。

## 已知状态

- 产品、架构、策略、数据、回测、机器学习、数据模型和 API 规格已合并为 `docs/系统规格说明.md`，并统一使用中文。
- 已建立 `backend/` Python 工程、Pydantic 领域模型、AKShare/BaoStock/歪枣网统一适配器契约、DuckDB 清单索引、内容寻址 JSON/Parquet 快照、质量门、安全策略 AST、下一交易日回测和股票分析 API；另有带 API 健康状态的最小 React/Vite 前端外壳。默认测试不访问网络；真实验证脚本位于 `backend/scripts/verify_live_adapters.py`。
- 已实现通达信半手动选股首个可验证切片：`tdx_import.py` 支持 UTF-8/GB18030 的 CSV、TSV、分号分隔文件和通达信 `.EBK` 市场前缀格式；批次记录公式和文件哈希；原始导出和解析结果不可变保存；人工标签和客观结果追加保存；`selection_outcomes.py` 支持明确固定持有期、政策指纹和名义金额的客观结果计算；`selection_stats.py` 按候选/追踪政策取最新结果并分离完成、未入场和未解决样本；FastAPI 候选队列/统计接口和 React 标注、统计页已接入。
- 歪枣网适配器支持按证券代码获取不复权日线，使用 `WAIZAO_TOKEN` 环境变量；`code=all` 当前 Token 无权限。成交量已从手转换为股，原始响应仍保留供应商字段。成交量和成交额交叉比较允许 0.001% 相对容差以覆盖供应商取整。
